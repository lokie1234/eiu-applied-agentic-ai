# EIU Applied Agentic AI - New Machine Setup

## Access codes
- 9999: Section 1
- 8888: Section 2
- 1103: Admin selector (both sections)
- 7879: Quiz access code (configure in Vercel)

## Setup
1. Clone GitHub repository.
2. Copy Vercel Environment Variables to .env.local.
3. Run:
   npm install
   npm run dev

## Required Vercel variables
SECTION_1_ACCESS_CODE
SECTION_2_ACCESS_CODE
ADMIN_ACCESS_CODE
QUIZ_ACCESS_CODE
QUIZ_SECTION_2_ACCESS_CODE
ACCESS_SESSION_SECRET
NEXT_PUBLIC_PDF_URL
GOOGLE_APPS_SCRIPT_URL
GOOGLE_APPS_SCRIPT_SECRET

Never commit real secrets into GitHub.
