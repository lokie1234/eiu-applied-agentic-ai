------------------------------
FILE — SKILL.md
------------------------------

Nội dung gồm:

File phải bắt đầu bằng YAML frontmatter hợp lệ:
---
name: business-web-app-builder
description: Mô tả 1–2 câu về nhiệm vụ và khi nào sử dụng SKILL.
---

Tên SKILL phải dùng chữ thường, phân tách các từ bằng dấu gạch nối (kebab-case).
Sau frontmatter là hướng dẫn Markdown hoàn chỉnh, ngắn gọn và rõ ràng.
Đặt SKILL.md ở cấp gốc để có thể upload trực tiếp vào Gemini SKILLS mà không cần file tham chiếu riêng.

Instructions phải quy định rằng khi người dùng đưa Requirement mới, SKILL phải:

1. Hiểu nghiệp vụ.
2. Áp dụng REUSABLE CORE từ phần kiến thức được tích hợp ngay trong SKILL.md.
3. Thiết kế data model, quyền, workflow và UI theo Requirement.
4. Tạo đúng 2 file code hoàn chỉnh:
   - Code.gs
   - Index.html
5. Code.gs phải chứa toàn bộ backend cần thiết:
   doGet,
   setup database,
   Google Sheets CRUD,
   authentication,
   session,
   account management,
   permissions,
   validation,
   audit,
   error handling.
6. Index.html phải chứa toàn bộ frontend:
   login,
   giao diện nghiệp vụ,
   admin account/permission management,
   Bootstrap 5 responsive,
   CSS,
   JavaScript,
   google.script.run,
   loading/success/error,
   logout.
7. Không dùng pseudo-code.
8. Không bỏ sót hàm.
9. Không dùng comment kiểu “code tiếp theo”.
10. Code phải đủ để copy vào Apps Script và triển khai.
11. Khi hệ thống hỗ trợ tạo file, xuất Code.gs và Index.html thành file tải xuống.

- Bootstrap 5 responsive.
- Desktop và mobile.
- Navigation rõ ràng.
- Form có validation.
- Loading, success, error state.
- Dashboard dùng stat cards, table, filter hoặc chart khi phù hợp.
- Admin screen tách rõ khỏi nghiệp vụ người dùng.

PART 3 — KNOWLEDGE_AUTH_RBAC_PATTERN
- Users, Permissions, Sessions, AuditLogs.
- Admin seed EIU8888 / EIU123.
- Password hash + salt.
- Session token khó đoán và có expiry.
- Backend authorization cho mọi API quan trọng.
- Permission theo module_key/content_key.

PART 4 — KNOWLEDGE_WORKFLOW_PATTERN
- Trạng thái nghiệp vụ phải được định nghĩa rõ.
- Chỉ role/quyền hợp lệ mới được chuyển trạng thái.
- Validate transition ở backend.
- Ghi người thao tác, thời gian và thay đổi vào audit/history.

PART 5 — KNOWLEDGE_GAS_SHEETS_PATTERN
- Apps Script backend + Google Sheets database.
- Setup sheet idempotent.
- Header rõ ràng.
- Chuyển dữ liệu Sheet thành Object[] để frontend dễ xử lý.
- Validate dữ liệu ở server.
- LockService cho thao tác ghi.
- Error response nhất quán.
- Không làm lộ lỗi hệ thống nhạy cảm.
- Hướng dẫn deploy:
  Apps Script Editor
  → Code.gs + Index.html
  → chạy setup
  → Deploy
  → New deployment
  → Web App
  → Execute as Me
  → chọn quyền truy cập phù hợp
  → lấy Web App URL.
