EIU LESSON PLAYER 1.0
====================

WINDOWS 10 / 11 (64-bit)
1. Giải nén toàn bộ gói tải về.
2. Mở EIU-Lesson-Player-1.0.0-win-x64.exe.
3. Chọn thư mục cài đặt và hoàn tất. Không cần cài Node.js.
4. Mở EIU Lesson Player từ Desktop hoặc Start Menu.

macOS — APPLE SILICON / INTEL
1. Chọn đúng gói arm64 (Apple Silicon) hoặc x64 (Intel).
2. Giải nén. Kéo EIU Lesson Player.app vào Applications.
3. Mở ứng dụng từ Applications.
4. Bản đầu chưa được Apple notarize: nếu macOS chặn, kiểm tra đúng nguồn
   tải GitHub của EIU rồi dùng System Settings > Privacy & Security > Open Anyway.
   Không cần tắt Gatekeeper hoặc thay đổi bảo mật toàn hệ thống.

MỞ BÀI HỌC
- Tải tệp bài học .js từ Learning Space bằng nút tải nội dung section.
- Trong ứng dụng, chọn “Mở bài học” hoặc kéo thả tệp .js vào cửa sổ.
- Chọn đúng bài học JS xuất từ Learning Space, không đổi đuôi TSX sang JS.
- ← / → hoặc Page Up / Page Down: chuyển slide; Esc: thoát toàn màn hình.
- Ctrl+O (Windows) / Command+O (macOS): mở bài học.
- Khung EIU được áp sẵn. Bài có thiết kế riêng giữ nguyên thiết kế gốc.
- Các ảnh, font nhúng và gói website mẫu đi kèm hoạt động trên máy.
- Link web, dịch vụ AI và localhost vẫn cần kết nối hoặc ứng dụng tương ứng.
- Không tự đổi ứng dụng mặc định của mọi tệp .js trên máy.

Bản đầu chưa có chứng thư ký ứng dụng Windows hoặc Apple Developer.
Windows có thể hiện cảnh báo nhà phát hành chưa xác minh.
