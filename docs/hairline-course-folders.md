# Hairline course folders

## Integration

The course library has a vertical folder sidebar and a separate course pane. `HairlineFolder` mounts the original Hairline kernel and the `course-folder` figure only in the folder buttons. The broad folder face points toward the viewer while retaining the isometric camera, with a tabbed back and three rounded sheets. Hover or keyboard focus lifts and spreads the sheets from the middle; the cover only tilts from 12–18° to 22°, so branding remains readable. The larger EIU logo from `/branding/eiu-logo-uploaded.png` follows the front cover's transform in the application adapter, as explicitly requested. Names and counts remain HTML outside the drawing. No hover or drag is required to choose a folder.

The redundant Folders heading/count and selected folder heading in the course pane are removed. Folder names in search results remain to distinguish groups. A selected folder has a brighter background, gold outline/left bar and check mark, plus native aria-pressed state; hover alone does not show the selected mark. Cross-group search clears the visual selected state until a folder is chosen or search is cleared. The mobile selected-folder toggle retains the name because it opens the folder menu.

Section counts share a full-width badge row with language and status, with a gold outline/background for the count. Summary text is 16px with 1.55 line height and up to two lines. Compact badge spacing keeps the three badges together at 360px while allowing wrapping for unusually long values.

The first group opens by default; a course deep link selects its group and course page. A previously selected group is retained when clearing search; a deleted group falls back to the first available group. Search checks all course titles, descriptions, and group names while the complete folder navigation remains available. Choosing a folder clears search and opens that group's courses.

Courses and folders each paginate at exactly six items: the seventh starts page two. The sidebar divides its available height into six equal rows, with an 8px gap and pagination reserved below them. Short desktop screens use smaller artwork and a compact header while preserving six visible folders. Folder names use 20px text on desktop (18px on compact screens), with two lines and a native full-name tooltip. Courses use two columns on desktop and one on smaller screens. The panel expands up to 1560px; the header has a larger title with a subtle animated underline. Course pagination stays outside the scrolling card grid. On mobile, the folder navigation becomes a vertical dropdown below the selected-folder button with six entries per page; the list can scroll on short screens to retain usable touch targets, while pagination stays visible. Choosing a folder or pressing Escape closes it.

All uploaded course tool icons are shown and wrap naturally. Their native hover labels use the uploaded names. Cards and icons are passive; a dedicated native Enter button opens each course. `HairlineEnter` draws a wide mechanical key with a tapered cap, inset rim, sleeve and socket. The outer button has no visible frame/background, and the artwork is enlarged to 156×112px (116×94px on mobile). The button fades in only when its course is hovered or contains keyboard focus, and stays visible on touch devices. Hover or keyboard focus depresses the cap and then the sleeve, with a 40ms stagger; leaving returns it to rest. The application adapter overlays an Enter label inside the SVG and follows the cap's projected top plane (including its two isometric axes) through data-label-transform via MutationObserver, as explicitly requested. An HTML label is the fallback if the artwork does not load. The canonical figure stays word-free; its source is `enter-key.js`, served unchanged at `public/hairline/enter-key.js`, and its standalone preview is `hairline-enter-key.html`.

Enter replaces the course grid with the selected course's sections in the same right pane, keeping folder context visible. The pane receives focus and starts at the top. The Courses button or Escape restores the original course page, scroll position and Enter-button focus. Choosing a section opens the existing presentation directly, preserving session authorization, slide restoration, uploaded PDF/TSX/PPTX decks, built-in decks, attachment preview/download and admin report/reset controls. There is no separate section-selection page or document navigation. Changing groups, course pages or search returns to the course list.

Course hover/focus-within brightens the card, highlights its border and side accent, and lifts it by 2px. Available section cards use the same small lift, a gold border and a brighter background. Their old arrow is replaced by a rounded wireless Hairline mouse with split buttons and a scroll wheel, plus a separate HTML Click label. It fades in on hover/keyboard focus, the left button depresses and the wheel follows by 40ms; the word makes one small upward nudge. The cue reserves space beside the text and stays visible on touch devices. Disabled sections have no click cue or lift. Reduced motion removes card movement and the label nudge; the shared kernel already settles immediately. The new mouse figure shares the existing cached engine and adds no dependencies or server data requests. Artwork is decorative and the existing native section button remains the only interaction target.

The overall panel, folder cards, courses and sections retain EIU navy and gold. Sage appears only in small accents and two decorative leaf/sprout marks beside the library title and section breadcrumb. All four Hairline figures share a dark blue fill, gold strokes and a subtle shadow through components/hairline/theme.module.css. Semantic data-part attributes distinguish the back/papers/cover, socket/sleeve/cap, mouse parts and loading beads. The original EIU PNG and its transform remain unchanged. The user's explicit color and branding requests are confined to the application adapter; canonical standalone figures retain the fixed Hairline palette without branding or text overlays.

`public/hairline/kernel.js` is an unchanged copy of the skill's kernel. The figure source is `course-folder.js`, served unchanged at `public/hairline/course-folder.js`. Its standalone artifact is `hairline-course-folder.html`; the engine and bench inside it are unchanged. The figure uses the package's monochrome weights; the host uses its supported theme variables to match the navy interface.

`components/hairline/runtime.ts` loads one engine and caches each figure from public, with no CDN or server data requests. Registration is serialized because figure files share a global registration callback; the Enter figure scopes its helper names to avoid script declaration collisions. One shared media-query listener handles reduced motion/coarse pointers. Figures destroy their listeners and unregister on unmount. The shared kernel loop sleeps when settled or offscreen. Coarse-pointer devices and reduced-motion users receive immediate state changes. Each moving part caches its own value so unchanged paths are not rewritten.

HairlineLoading shows five rounded beads lifting in a wave while a section session request, dynamic deck import, uploaded slide layout, TSX iframe, PDF document/page or PPTX preview is pending. The request hook prevents duplicate opens, cancels on leaving the selection pane, ignores late replies and shows a retryable error on failure or a 30-second timeout. Deck controls, preview/download links and existing authorization stay intact. The loader disappears on ready/error and destroys its figure on unmount. It uses one cached script, the shared kernel clock and no additional timer, animation library, server endpoint or fake progress. Reduced-motion/coarse-pointer devices show static beads; offscreen work sleeps. A live status label and static fallback remain available if artwork fails.
