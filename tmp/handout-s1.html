QUY TRÌNH 8 BƯỚC THỰC CHIẾN TỪ IDEA ĐẾN WEB APP
01
Xác định bài toán & người dùng

Chốt rõ: Ai sử dụng? Dữ liệu đầu vào gồm những trường nào? Luồng duyệt ra sao và người quản lý cần xem bảng dữ liệu nào?

02
Chuẩn bị Google Drive & Google Sheets

Tạo thư mục Applied Agentic AI trên Drive. Tạo 1 Google Sheet làm Database trung tâm để lưu trữ toàn bộ dữ liệu ứng dụng.

03
Thiết kế cấu trúc bảng dữ liệu (Schema)

Đặt tên các cột rõ ràng: Họ tên, Ngày bắt đầu, Ngày kết thúc, Lý do, Trạng thái (Chờ duyệt/Đã duyệt/Từ chối), Timestamp.

04
Viết Prompt chuẩn 5 thành phần

Cấu trúc: Mục tiêu + Người dùng + Dữ liệu + Quy trình + Công nghệ yêu cầu (Google Apps Script + HTML/CSS/JS).

05
Đính kèm EIU Design DNA (design-dna.txt)

Tải file design-dna.txt và gửi kèm Prompt để Gemini tự động thiết kế giao diện chuẩn Navy #082945 & Gold #B39159, responsive và sang trọng.

06
Tạo cấu trúc 4 file trong Apps Script

Mở Extensions > Apps Script. Tạo đủ 4 file: Code.gs (Backend), JavaScript.html, Style.html và Index.html (Frontend).

07
Lưu ý tạo file & xóa sạch code mặc định

Bắt buộc: Tên file phân biệt hoa/thường (Case-sensitive). Phải xóa sạch nội dung mặc định trong file vừa tạo trước khi dán code mới.

08
Triển khai (Deploy) & Kiểm thử

Chọn Deploy > New deployment > Web app. Cấu hình Who has access: Anyone. Sao chép URL kết thúc bằng /exec và nhập form thử nghiệm.
