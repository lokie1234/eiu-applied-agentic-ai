# MIS 311 visual design

Apply public/downloads/design-dna.txt. The current course template is EIU
without reference (86101dcf-70f4-49c3-a6a9-983c77708ad2), 16:9.
Native transparent lesson content occupies left 5.6%, top 11.5%, width 88.8%,
height 77.4%. Reserve all header logos and footer numbering. Never paint over
the frame. Size typography against both content width and height.

Use navy #144069/#17324A, gold #B39159, soft cream #FBFAF7 and restrained blue.
Keep diagrams native SVG/HTML, with generous label padding and clear routing.
In the techniques slide, a four-tab navigation selects one full-size technique.
BPMN has Example/Notation; UML directly shows a connected hierarchy, with no
secondary view buttons or activity example. Use warm yellow, peach and coral
nodes by hierarchy level, with fine coral connectors and readable navy text.
Keep flow
semantics correct, including message flow between pools, sequence flow within
pools and lanes within a participant. Four techniques must remain distinct:
BPMN collaboration, UML classification, flowchart decisions, Gantt time.
Use the original slide 6 figures and slide 8-10 meanings as content sources.
All diagram labels remain text. Avoid bitmap diagrams, crowded dashboards,
opaque full-slide panels and tiny legends. Support keyboard and reduced motion.
